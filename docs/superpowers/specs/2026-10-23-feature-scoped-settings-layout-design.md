# 功能就近设置布局 — 设计文档

- 日期：2026-10-23
- 状态：已批准并实现
- 范围：`src/ui`、`README.md`；不改变设置数据结构、不改动答题/翻页/题库业务逻辑
- 前置：`docs/superpowers/specs/2026-10-22-settings-consolidation-media-fix-design.md`

## 1. 背景与目标

设置页目前集中了 7 个板块，其中「答题」「AI 接口」「自动翻页」「题库与缓存」都属于某个具体功能，用户必须离开当前功能页、进入设置页找到对应板块、改完再切回来。

本次按「功能 + 它的设置放同一区」重新分区：

1. 每个设置只有一个入口，与它影响的功能在同一 Tab。
2. 设置页只保留跨功能的全局项：外观、快捷键、高级适配器、数据与隐私、运行日志。
3. 功能页的设置区默认收起，不挤占首屏的操作与内容区域。
4. 纯 UI 重排，不新增设置字段，不改变任何运行时行为。

## 2. 信息架构

| Tab | 功能区 | 同区设置 |
| --- | --- | --- |
| 主页 | 页面状态、统计、快捷操作、自动翻页控制（开始/结束、已翻页、倍速） | 自动翻页：启用、等待媒体结束、遇未答题目暂停、刷新恢复；媒体播放：默认静音、暂停后恢复 |
| 答题 | 扫描 / 解题 / 全部填入 / 提交、进度、筛选、题目列表 | 答题设置：模式、自动提交、简答、考试保护、最低置信度；AI 接口：启用、预设、Base URL、Key、模型、测试连接 |
| 题库 | 统计、导入 / 导出、检索 | 题库设置：模糊匹配阈值、缓存保留天数、远程题库接口 |
| 设置 | —（仅全局） | 外观与快捷键、高级与通用适配器、数据与隐私、运行日志 |

AI 接口放在「答题」而不是「设置」：它是解题能力的来源，与题库一起决定答案从哪来；放在答题页可以边看题边配置。

## 3. 交互规则

- 设置区统一使用 `CollapsibleCard`：标题 + 当前值摘要；展开后显示原有表单。
- 默认展开状态：
  - 功能页（主页 / 答题 / 题库）的设置区全部收起；
  - 设置页只展开「外观与快捷键」，其余收起。
- 跨页入口改为「切到对应 Tab 并展开对应设置区」：
  - 主页考试保护提示 → 答题 · 答题设置（`solve.solving`）；
  - 主页缺少 API Key 提示 → 答题 · AI 接口（`solve.ai`）；
  - 题库的远程题库入口 → 题库 · 题库设置（`bank.settings`）；
  - 主页「翻页设置」→ 原地展开主页的自动翻页设置（`home.autoTurn`），不再跳转设置页。
- 「全部展开 / 全部收起」只作用于当前页面的板块；设置页仍保留该工具条，功能页不加工具条。
- 折叠状态使用带页面前缀的 key：
  `home.autoTurn`、`solve.solving`、`solve.ai`、`bank.settings`、
  `settings.appearance`、`settings.advanced`、`settings.data`、`settings.logs`。
  旧 key（`solving` / `ai` / `autoTurn` 等）不再读取，保证新默认值直接生效；旧值留在存储中不报错。
- 同一设置不在两处出现：迁移后设置页不再包含答题、AI、自动翻页、题库配置。

## 4. 组件拆分

- 新增 `src/ui/sections.ts`：板块 key 常量、默认展开值、`isSectionOpen` / `toggleSection` / `openSection` / `setAllSections` 辅助函数。
- 新增 `src/ui/panels/`：
  - `SolvingPanel.tsx`：答题模式、自动提交、简答、考试保护（含二次确认）、最低置信度；
  - `AiPanel.tsx`：AI 开关、预设、Base URL、Key、模型、测试连接与清除 Key；
  - `AutoTurnPanel.tsx`：翻页开关与媒体播放开关；
  - `BankPanel.tsx`：模糊阈值、缓存天数、远程题库配置。
- `pages/Home.tsx`：在自动翻页控制卡下方内嵌自动翻页设置；跨页入口改为「跳 Tab + 展开板块」。
- `pages/Solve.tsx`：操作卡下方内嵌答题设置与 AI 接口两个折叠区。
- `pages/Bank.tsx`：检索卡之后内嵌题库设置；移除重复的远程题库状态卡与跳转按钮。
- `pages/Settings.tsx`：只保留外观与快捷键、高级与通用适配器、数据与隐私、运行日志 4 个板块。
- 页面从 `settings.ui.sectionStates` 读取状态，保存时只写当前操作的 key。

## 5. 非目标

- 不修改 `Settings` 接口字段与默认值。
- 不修改自动翻页、媒体、答题、题库、AI 的运行逻辑。
- 不改变 4 个 Tab 的数量与名称。
- 不引入新的运行时依赖。
